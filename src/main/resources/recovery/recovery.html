Epic IT POS cannot open its data

The POS did not start because its data file is damaged or unreadable. This can happen after a power cut. No sales can be taken until it is fixed.
Your damaged file is not deleted. If you restore a backup, the damaged file stays in the data folder (named epicit-pos.mv.db.before-restore-…) so it can still be examined. Sales made after the backup was taken will be missing from the restored data.
